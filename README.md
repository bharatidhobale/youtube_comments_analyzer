## **Overview**
The **YouTube Comments Analyzer** is a web-based application that performs sentiment analysis on YouTube video comments. It categorizes comments into **Positive**, **Negative**, and **Neutral** sentiments and visualizes the results using a **pie chart**. The application also calculates the **audience engagement percentage** for the video.

Additionally, the project includes:
- **Registration Form**: Securely stores user credentials in a database with encrypted passwords.
- **Contact Form**: Allows users to submit feedback or inquiries, storing the data in the database.

---

## **Features**
- Sentiment analysis of YouTube comments.
- Visualization of sentiment distribution using a pie chart.
- Calculation of audience engagement percentage.
- Secure user registration with password encryption.
- Feedback and inquiry handling via a contact form.

---

## **Technologies Used**
- **Backend**: Node.js, Express.js
- **Frontend**: HTML, CSS, JavaScript
- **Database**: MySQL
  

---

## **System Requirements**
- **Internet Connection**: Required to access YouTube comments.
- **Node.js**: Ensure Node.js is installed on your system.

## **Setup Instructions**

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/YourUsername/youtube-comments-analyzer.git
```

### 2️⃣ Navigate to the Project Directory
```bash
cd youtube-comments-analyzer
```

### 3️⃣ Install Dependencies
```bash
npm install
```

### 4️⃣ Start the Application
```bash
node app.js
```

### 5️⃣ Access the Application
Open your browser and navigate to:  
[http://localhost:3044](http://localhost:3044)

---

## **How It Works**

1. **Analyze Comments**
   - Enter a YouTube video URL in the input field.
   - Click on the **Analyze** button to get the sentiment analysis results and audience engagement percentage.

2. **User Registration**
   - Fill out the registration form and click **Register**.
   - Credentials are securely stored in the database with encrypted passwords.

3. **Contact Form**
   - Submit doubts or feedback through the contact form.
   - Feedback data is stored in the database for further review.
